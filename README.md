# GALA MARKET — 2단계 전환형 시연 웹사이트

## 바로 열기
`index.html`을 브라우저에서 열면 됩니다. 혹은 GitHub Pages로 배포할 수 있습니다.

## GitHub Pages
1. `gala-market-final` 저장소 최상위에 `index.html`, `styles.css`, `app.js`, `README.md`, `assets` 폴더 전체를 업로드합니다.
2. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
3. `https://깃허브아이디.github.io/gala-market-final/` 형식의 주소를 엽니다.
4. 이전 파일이 있다면 같은 이름을 덮어써야 하며, ZIP 파일 자체를 올리지 마세요.

## 흐름
참가자 이름 등록 → 대기실 → 대회 안내·8개 기업 → 1라운드 뉴스/거래/잠금/결과 → 2라운드 가상 미국 대선/거래/잠금/결과 → 3라운드/거래/잠금/결과 → 4라운드/거래/잠금/결과 → 최종 개인 결과.

## 시연 한계 (중요)
- 이 코드는 **단일 브라우저 시연용**입니다. 참가자 등록 이름의 중복 검사·인증·실제 관리자 권한·실시간 50명 동기화·전체 순위는 구현되지 않았습니다.
- 관리자 시연 버튼은 사용자에게 공개되어 있으며 실제 안전한 관리 권한이 아닙니다.
- 추첨은 브라우저의 `crypto.getRandomValues`를 이용한 시연이며, 결과는 이 기기에 저장됩니다. 실전에는 **보호된 서버에서 주문 마감 이후 추첨, 정산, 공개**가 필요합니다.
- 같은 산업군의 두 기업은 같은 방향(둘 다 상승 또는 둘 다 하락)이고 서로 다른 변동률이며 절댓값은 1~29.9%입니다. 다른 산업 방향은 각자 무작위입니다.
- 모든 금액과 뉴스는 교육용 가정 수치, 가상 시나리오입니다. 실제 투자에 사용하지 마세요.
- 뉴스 배경 이미지는 AI 생성 시안에서 추출한 이미지입니다.
